QUICK FIX for "sbt run" error:

Use this command instead:
  sbt "project engineApi" run

Or use the script from project root:
  ./scripts/dev-run.sh

The error occurs because:
- "sbt run" tries to run the root project
- The root project is just an aggregator (no main class)
- The actual main class is in engine-api project

Solution: Always specify the project to run
